# PavanSoni_Capstone_MASAI

Capstone project for the MASAI Data Science & AI program. Built on the Olist
Brazilian E-Commerce dataset.

Each part is in its own folder with a dedicated README documenting how to run it
and how it meets the acceptance criteria.

## Contents

- **[part1](./part1)** — Data Foundations: SQL extraction, cleaning & outlier audit (SQLite + Pandas).
- **[part2](./part2)** — Statistical EDA, hypothesis testing & visualization (Pandas, NumPy, SciPy, Seaborn).
- **[part3](./part3)** — GenAI-powered text analytics: prompt engineering & LLM API integration (Google Gemini).
- **[part4](./part4)** — Agentic AI system: tool-using agent (LangChain + Gemini).

## Notes

- API keys are loaded from `.env` files and are never committed (excluded via `.gitignore`).
- Raw source CSVs and the SQLite database are excluded from the repo; see each part's README for how to obtain/regenerate them.
